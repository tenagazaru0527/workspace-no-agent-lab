# Workspace No-Agent Lab

Google Workspace の標準機能で、小さな業務改善を試すための公開ラボです。最初の題材は GitHub Issues のような「起票 → 担当を決める → 対応 → 完了」の運用です。

**流れは一方向：個人PC・GPTで作成 → この公開GitHubへ掲載 → 利用する側はログインなしで閲覧／必要なファイルだけダウンロード。** このリポジトリは資料置き場であり、業務チケットを登録する場所ではありません。利用先からの投稿・同期・情報の持ち出しは想定しません。

ファイルをまとめて取得するなら、リポジトリ上部の **Code → Download ZIP**。現場でダウンロード・外部資料の取り込みが許可されている場合だけ使ってください。ダウンロード不可でも、手順はブラウザ上で読めます。現場側で台帳を作るときは、承認済みの Workspace アカウントで構築してください。

## 比較する順番

| 候補 | 何を楽にするか | 判断 |
|---|---|---|
| Sheetsのみ | 台帳・担当・期限・集計 | 最初に試す。外部接続、実行コード、AIエージェント不要 |
| Forms＋Sheets | 起票者に台帳の編集権限を渡さず受付 | 次に試す。受信箱と採番は手動 |
| Sites＋Forms＋Sheets | 入口・手順・チーム向け一覧を1か所に集める | 利用者が迷う場合に足す。権限は別々に確認 |
| Apps Script / AppSheet | 採番・通知・履歴の自動化やアプリ化 | 管理者の許可・実行者・ライセンスを確認後。P0の前提にしない |

次の実験候補は、レビュー指摘の回収、議事録からアクション項目を引き継ぐ表、公開アドバイザリの一次判定チェック表です。最初から全部は導入しません。

## 公開に載せないもの

実データ、内部URL、組織・顧客・担当者情報、内部資料、アカウント情報、社内画面のキャプチャは掲載しません。Issue・コメントにも書かないでください。実運用のデータ・設定・利用結果は利用先の承認された保存先に残します。
