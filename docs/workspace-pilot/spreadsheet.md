# 試し刷り確認票をExcelとSheetsで比べる

[完成見本（.xlsx）](proof-print-sample.xlsx)は、架空の案件LAB-105の確認票です。黄色の **C6:C8（実績）、E6:E8（確認メモ）** が入力欄です。案件の担当や状態を更新する場所は元のIssue台帳で、この表は一時点の出力見本です。

## 元資料と期待値

[架空ケースのE-02](case.md#e-02-証跡試し刷りの実施)と、次のR-01を使用します。D-02の承認範囲を変える作業は含みません。次の記録は帳票のために用意した架空の資料です。

```text
R-01 v1｜2030-04-04｜LAB-105 確認票用｜用紙担当が記録
追加印刷は予定0枚、実績0枚。計画時に予備用紙2枚を見込んだ。実際の残数は未確認。
```

| 行 | A 確認項目 | B 計画 | C 実績 | D 差 | E 確認メモ |
| --- | --- | ---: | ---: | ---: | --- |
| 6 | 試し刷り（枚） | 3 | 3 | 0 | E-02の実施記録で確認。 |
| 7 | 追加印刷（枚） | 0 | 0 | 0 | R-01に追加印刷0枚と記録。 |
| 8 | 予備用紙（枚） | 2 | 空欄 | 空欄 | R-01の残数は未確認。用紙担当に確認する。 |
| 10 | 計画合計／実績小計 | 5 | 3 | 空欄 | 未入力件数は1（E10）。 |

## 1. 比較前に書式を固定する

1. 見本を複製します。Sheetsで試す場合は、許可された場所で開き「ファイル」→「Google スプレッドシートとして保存」。A1:E11を画面・印刷の対象にします。Sheetsでは範囲を選択して「ファイル」→「印刷」→「選択中のセル」。Excelデスクトップでは「ページレイアウト」→「印刷範囲」→「印刷範囲の設定」。双方でA4横・1ページに設定し、列幅・折り返しと文字の見やすさをプレビューで確認します。 [Sheetsで印刷](https://support.google.com/docs/answer/7663148?hl=en) · [Excelの印刷範囲](https://support.microsoft.com/en-us/excel/set-or-clear-a-print-area-on-a-worksheet) · [Excelの拡大縮小](https://support.microsoft.com/en-us/excel/fit-to-one-page-in-excel)
2. 複製のC6:C8とE6:E8を**内容だけ**消し、見本にそろえます。計画、タイトル、見出し、数式、列幅、印刷範囲、数値・日付の書式は固定。日付B3は日付型で yyyy-mm-dd 表示、数値は整数（0も表示）。E列を折り返し、見出しを固定し、C6:C8には空欄または0以上の整数を入れます。
3. 誤編集対策に、Sheetsでは見本の編集者を絞るか、試行コピーで入力欄以外を保護します。入力欄は値のみ貼り付け、保護の有無に関係なく数式と書式を目視で照合します。取得が許可されない場合は下のセル指定を使って空のSheetsで再現できます。 [Sheetsの範囲保護の仕様](https://support.google.com/docs/answer/1218656?hl=en)

**手入力で再現する場合。** A2「試し刷り確認票」、A3「基準日」、A4に対象IDと入力欄の案内、A5:E5に上表の見出し、A6:B8に上表の項目名と計画数を置きます。A10に「計画合計／実績小計」、E9に「実績の未入力件数」、A11に「実績小計は入力済みの行のみ。空欄は未確認。」。見出しは濃紺に白字、入力は薄い黄色、集計行は淡い青灰色。A〜Eの列幅（Excel単位）は24、13、13、13、43を目安にします。E6:E8を折り返します。

```text
B3   =DATE(2030,4,4)
D6   =IF(COUNT(B6:C6)<2,"",C6-B6)
     D6をD8までコピー
B10  =SUM(B6:B8)
C10  =SUM(C6:C8)
D10  =IF(COUNT(C6:C8)<COUNTA(A6:A8),"",C10-B10)
E10  =COUNTBLANK(C6:C8)
```

引数の区切りはシートの言語設定に合わせます。実績の合計は確認済みの数値だけの小計で、未入力がある間は合計差を空欄にします。確認済み値が0の場合は0を入力します。

## 2. 手入力版とLLM補助版を作る

同じ書式の空欄コピーを二つ作り、同じE-02とR-01を使います。人が手入力して確認した版と、Gemini新規チャットで値の案を作ってから人が確認した版を比較します。手順に慣れる影響を見たいときは、翌回に二人の実施順を入れ替えます。Geminiへは完成値入りの見本と上の期待値を渡さず、項目名・セル範囲・元資料を渡します。

```text
指定した架空資料 E-02 と R-01 だけを使って、試し刷り確認票への入力案を作る。
対象は C6/E6 試し刷り、C7/E7 追加印刷、C8/E8 予備用紙。
各行を「行番号／実績値／短い確認メモ／根拠資料ID・箇所」で返す。
実績は資料で確認できた0以上の整数。計画値を実績に使わない。
未確認なら実績値を空欄とし、確認メモに必要な確認先を書く。
入力値と短いメモだけを提案し、数式・書式の変更は提案しない。
```

人が資料を開いて各値を照合し、二つの入力範囲へ値のみを入れます。根拠欄は採点に使用します。Geminiが使えない場合は人の版だけを作り、時間比較は未実施にします。

## 3. 書き出しと採点

Sheets版は「ファイル」→「ダウンロード」→「Microsoft Excel（.xlsx）」で保存。Excelが使える場合は、対象の版とOSを記録し、書き出したファイルを開き直します。印刷範囲とA4横1ページになっているかを確認し、必要なら直す時間も測ります。PCに保存が残らない前提なので、許可された試行用保存先に置きます。 [SheetsからExcel形式のコピー](https://support.google.com/docs/answer/9331167?hl=en) · [Excelの改ページ表示](https://support.microsoft.com/en-us/excel/view-page-breaks)

| 確認 | 合格値・判断基準 |
| --- | --- |
| 日付・値・型 | B3は2030-04-04として表示。C6=3、C7=数値の0、C8は空セル。確認メモには根拠、未確認分には確認先。 |
| 再計算 | D6/D7は0、D8/D10は表示空欄。B10/C10/E10は5/3/1。試験コピーでC8に数値2を入れるとD8=0、B10:E10は5/5/0/0。C8を消すと元に戻る。数式エラーがない。 |
| 見た目・印刷 | 見本と照合し、画面でもA4横1ページの印刷プレビューでも見出しや日本語を読める。折り返し・列幅・色分け・範囲・改ページを確認。Excelの書式差が手直しで解消できたかを記録。 |
| 手直し時間 | それぞれで入力、根拠照合・修正、Excelで開いてからの確認・修正を別に計測。下の記録表に分・秒を残す。双方が品質に合格し、LLM補助版の総時間が人の版以下なら今回の試行で採用候補。 |
