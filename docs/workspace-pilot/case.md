# 架空ケース　案内カードの試し刷り

すべて架空です。Aは以下の資料ブロックをコピーして使います。Bには[資料一覧](#資料一覧)と該当段階の原本だけを渡します。Aは[採点表](verification.md)と次の段階の資料を手元に置きます。このページ全体をGeminiへの入力に使うと、将来の決定まで渡してしまいます。

## 資料一覧

一覧だけを案内用DocsまたはSitesに写し、実際に原本として置いたDocs・台帳へのリンクをAが設定します。台帳はIDで特定します。資料識別子はそのまま使い、各文書の冒頭にも付けます。

| ID | 原本・節 | 版と状態 | 適用範囲・管理者 |
| --- | --- | --- | --- |
| C-01 | チーム概要「試し刷りの条件」 | v1・承認済み | 試し刷り1件。A |
| T-01 | 台帳「LAB-105」の行 | H列の更新日と試行段階で確認 | 現在の状態・担当・次の一手。更新時点の担当 |
| D-01／D-02 | 判断記録「LAB-105」の各節 | 初回はD-01が有効。最終回はD-02が有効 | 案の採否と理由。A |
| N-01 | 会議メモ「旧提案」 | 参考・未承認 | 当時の提案の出典。A |
| E-01 | 証跡「判読確認」 | v1・受領した段階から使用 | 等倍の判読結果。B |
| E-02 | 証跡「試し刷りの実施」 | v1・完了段階から使用 | 3枚の実施結果。B |

- 初回セットは **C-01、T-01（初回）、D-01、N-01**。資料一覧の初回版にはこの4件だけを載せます。
- 参照不能セットは初回セットから **D-01本文を外す**。一覧上のD-01には「参照不能」と追記し、N-01は残します。Bは参照不能試験の新規チャットで、費用も確認できるかを追加で尋ねます。実権限の試験をする場合は、AがBと未共有の架空の別ファイルにD-01を置き、B自身が閲覧できないことを確認します。Bが初回のD-01を開く前に別ファイルで行っても構いません。情報を外す模擬試験と、実権限の試験を判定表で区別します。
- 翌回セットは **C-01、T-01（翌回）、D-01、N-01、E-01**。
- 完了セットは **C-01、T-01（完了）、D-01（失効注記付き）／D-02、N-01、E-01、E-02**。D-01とD-02を同じDocsの各節に置けます。E-01、E-02は受領後に資料一覧へ加えます。

## C-01 チーム概要「試し刷りの条件」

```text
C-01 v1｜承認済み｜2030-04-01｜適用 LAB-105｜管理 A
目的：架空の案内カードを読みやすくする。
優先順位：判読性を確かめてから試し刷りする。
制約：承認された場合の上限は試し刷り3枚。一般配布は別の承認が必要。
完了条件：Aが承認し、Bが承認範囲内で試し刷りを行い、枚数と実施を記録した時点。
判断の役割：Aが採否を決め、Bが証跡を確認して台帳の現在地を更新する。
```

## N-01 会議メモ「旧提案」

```text
N-01｜参考・未承認｜2030-04-01｜適用 LAB-105
旧提案：A案（文字を小さくした案）を木曜2030-04-04に3枚試し刷りする。
このメモは会議中の提案。採否と日付は承認前だった。
```

## D-01 判断記録「A案の保留」

```text
D-01｜有効・承認済み｜2030-04-02｜適用 LAB-105｜決定者 A
決定：A案の試し刷りを保留する。実施日と配布は承認しない。
理由：等倍で読めるかの確認記録がない。
根拠：C-01「優先順位」「制約」、N-01「旧提案」。
見直し条件：等倍での判読記録を受領し、Aが改めて明示的に承認する。
後継：なし
```

## T-01 台帳「LAB-105」の行

[既存試作](../../experiments/01-issue-tracker/README.md)のA〜J列に合わせています。A〜Jをタブ区切りで貼るか、表示順に手入力します。日付列は日付型、空欄は空欄のまま。I列のD-01／D-02は判断記録へのリンクにします。下記は採点用の時点別の値です。試行用台帳にはいつもLAB-105が1行だけあります。

**初回。** 件名と起票元で起票し、Aが「対応中」にした後、D-01を承認して「確認中」にします。Bの受領時に次の値へ更新します。FとJは空欄です。

```tsv
ID	件名	担当	状態	優先度	期限	次の一手	更新日	起票元・資料	完了・見送り理由
LAB-105	案内カードの試し刷り	担当B	確認中	中		担当Bが資料担当に等倍の判読記録を確認する	2030-04-02	N-01／D-01	
```

**翌回。** E-01を受領し、GとHだけを変更します。以下は新規チャットへ渡す行の抜粋です。

```tsv
ID	件名	担当	状態	優先度	期限	次の一手	更新日	起票元・資料	完了・見送り理由
LAB-105	案内カードの試し刷り	担当B	確認中	中		判読記録E-01受領。担当Bが決定者Aへ承認を依頼する	2030-04-03	N-01／D-01	
```

**完了。** D-02承認後に「対応中」、E-02を照合して「完了」へ。I列には起票元と最新判断、J列には完了根拠への参照を記します。FとGは空欄です。

```tsv
ID	件名	担当	状態	優先度	期限	次の一手	更新日	起票元・資料	完了・見送り理由
LAB-105	案内カードの試し刷り	担当B	完了	中			2030-04-04	N-01／D-02	E-02（D-02の範囲で実施）
```

## E-01 証跡「判読確認」

```text
E-01 v1｜2030-04-03受領｜適用 LAB-105｜確認 担当B
等倍の確認画像で、A案の見出しと本文を読み取れた。
確認対象は判読性。費用・一般配布・実施日は確認範囲外。
```

## D-02 判断記録「試し刷り3枚を承認」

```text
D-02｜有効・承認済み｜2030-04-04｜適用 LAB-105｜決定者 A
決定：A案の試し刷り3枚を承認。一般配布は承認範囲外。
理由：等倍の判読記録で、見出しと本文を読めることを確認した。
根拠：E-01「等倍の確認画像」、C-01「制約」「完了条件」。
見直し条件：枚数・版面・配布範囲を変えるとき。
前の判断：D-01（失効）。D-01の状態欄を「失効・後継D-02」に更新する。
```

## E-02 証跡「試し刷りの実施」

```text
E-02 v1｜2030-04-04記録｜適用 LAB-105｜記録 担当B
D-02の範囲内でA案を3枚試し刷りした。一般配布は実施していない。
```
