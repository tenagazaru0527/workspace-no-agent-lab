# 二人で一件の判定表

Aが採点します。Bはケース本文全体・採点表・前回回答を受け取らず、資料一覧から当日の参照先を開きます。Bが回答をそのまま写すのでなく、決定・現在地・次の行動と根拠を説明できるか確かめます。採点結果は許可された試行用Docsなどに残します。

| 試験 | 合格に必要な結果 | 不合格時に確かめてから再試行する箇所 |
| --- | --- | --- |
| 入口と権限 | B自身が入口からC-01・T-01・D-01・N-01を開ける。入口だけ開けた場合は原本権限を未確認と記す。 | Sitesと原本の権限を別に確認し、許可された原本への直接リンクで試す。 |
| 初回の引き継ぎ | Bは「判読性を先に確認、上限3枚、一般配布は別承認」とC-01を示す。「確認中／担当B／期限未定／資料担当に等倍の判読記録を確認」はT-01。試し刷りの保留と理由はD-01。木曜はN-01の未承認提案。 | 原本の承認状態・見出し・台帳行の日付・添付範囲を確認。資料を手動で選び直して新規チャットで実行。 |
| 参照不能と情報不足 | D-01本文は参照不能と明言。T-01から確認中と次の確認先は言える。D-01の正式な判断・理由は根拠未確認。N-01で決定や木曜の期限を補わず、資料所有者への確認を挙げる。費用を問われても資料に記載なしと区別する。 | D-01の本文や旧回答が入っていないか、指定外の検索が有効でないか確認。後からD-01を許可範囲で指定し、新規チャットで回答が変わるか比較。 |
| 翌回の新規チャット | E-01で判読は確認済み。T-01（2030-04-03）は確認中、担当Bが決定者Aへ承認を依頼、期限は未定。D-01は有効で、まだ実施の承認は出ていない。旧提案や旧台帳の確認作業に戻らない。 | T-01の更新日、送った抜粋、Projectsの指定先と参照元を照合。最新の対象行と証跡を手動で指定して再試行。 |
| 完了と判断の更新 | 新規チャットでD-02を現行、D-01を失効と扱う。D-02は試し刷り3枚のみ。E-02で実施を示し、T-01（2030-04-04）は完了、担当B、次の作業なし。一般配布は承認も実施もされていない。IDは台帳に1行。 | 決定記録の後継ID、I/J列のリンク、台帳の重複、D-02の範囲を確かめる。矛盾が残れば担当と決定者が照合し、確定回答は保留。 |
| 一次下書き | 翌回セットでは判読確認済み・Aの承認待ち。3枚は条件つき上限。一般配布は別承認、費用は未回答。原本と節を照合でき、Aが承認・修正・保留を明示した。 | 根拠のない行を未回答へ戻し、確認先を定める。Bが修正してAに再提示。 |
| Projects／Skillsの比較（任意） | 手動指定と同じ現行の根拠にBが到達。利用できた画面、Bの原本権限、更新後の版を記録できた。 | 利用者の画面・プラン・Beta・共有の設定を切り分け、手動指定に戻す。 |
| 表計算（任意） | [完成見本の比較手順](spreadsheet.md)で指定セル・値・数式・見た目・手直し時間の判定ができた。 | Excel実機が使えなければExcel欄は未実施。差分があれば値、式、レイアウトを順に原因確認。 |

入口から完了までの最初の5行がすべて○なら、試した経路で合格です。必須のどれかが×または未実施なら、直した経路で該当項目と後続項目を再試行します。資料を外す模擬試験の○は実権限の確認を兼ねません。利用できた個別機能の結果は、各行の根拠と一緒に残します。

```tsv
試験日	試験項目	方法（手動指定／Projects／Skills／人が読む等）	指定資料ID・版	開けた資料／参照不能	観察した結果と根拠	判定（○／×／未実施）	再試行する箇所
```
