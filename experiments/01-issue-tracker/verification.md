# P0 検証記録

## 確認した範囲

架空データのみ。個人側の Google Sheets 上で台帳・集計・手動履歴を作り、行変更後に Google Sheets の計算結果を読み返した。フォーム送信や Sites 画面を通した試験ではない。

| ケース | 未完了 | 期限超過 | 担当未設定 | 重複ID行数 | 結果 |
|---|---:|---:|---:|---:|---|
| 初期状態 | 3 | 1 | 0 | 0 | PASS |
| 起票・担当未設定 | 4 | 2 | 1 | 0 | PASS |
| 担当割当・対応中 | 4 | 2 | 0 | 0 | PASS |
| 重複IDを追加 | 4 | 2 | 0 | 1 | PASS |
| 重複を解消 | 4 | 2 | 0 | 0 | PASS |
| 理由を付けて完了 | 3 | 1 | 0 | 0 | PASS |

## 採用する側で試すこと（未検証）

架空の問い合わせ1件を使い、自組織の規程と権限の範囲内で試す。1〜3を満たせば **Sheets の小規模試行**は可能。4〜6を満たすまで **Forms／Sites を含む採用**とは扱わない。

- [ ] GitHub未ログインでこのREADME・各資料が読める。ダウンロードを使う場合、許可の範囲でCSVやZIPも取得できる。
- [ ] 台帳担当が1件登録し、担当割当 → 対応 → 完了。並べ替えてもIDが変わらず、完了理由が残る。
- [ ] 閲覧者は一覧を見るだけで、台帳を編集できない。現場データの外部送信・個人GitHubへの反映が一切発生しない。
- [ ] Formsの回答権限がある人が1件送信し、回答が受信箱に1行だけ届く。受付担当が台帳へ固定ID付きで1件転記できる。
- [ ] 権限を持つ人が Sites の入口からフォームと一覧に到達する。未許可のアカウントおよび未ログインでは、対象のSite・回答・台帳が閲覧できない。
- [ ] 埋め込みだけ不可なら通常リンクでやり直す。組織の機能・権限制限が原因なら公開範囲を広げず、Sheets単体に戻す。

未検証：利用先の設定、権限差、別アカウント、Forms／Sites の実画面、同時編集、定期通知。GitHub からの自動取得やデータ同期は作らない。
